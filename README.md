# もぐもぐ掲示板

## 概要
食べ物について自由に投稿・会話ができる掲示板アプリです。
ユーザーがスレッドを作成し、おすすめのレストランや献立などについて投稿することができます。

## 使用技術
・Java
・Servlet
・JSP
・SQL server
・HTML/CSS

## 機能
・スレッド作成
・会員登録
・ログイン/ログアウト
・スレッドの表示
・スレッドの検索
・投稿機能
・画像の投稿
・ログインしていない場合は閲覧のみ可能

## 工夫した点
・投稿日時が表示できる
・投稿数でランキング化し掲示板を表示
・ログイン状態によって投稿の可否を制限
・トップページだけでなくスレッド一覧のページへ移動できるよう実装
・セッション、フィルターを使用しログイン状態が保たれない場合はログアウト画面へ移動するよう実装
・管理人でログインすると投稿の削除、掲示板の削除が可能

## 今後追加したい機能
・一般ユーザーでログインした場合、自分投稿を削除する機能
・会員の削除
・いいね機能
・特定の投稿に返信する際、リンクをつける
